# Ambiente de IA do EasyVan

Este diretório prepara o workspace para uso com agentes de IA e ferramentas como OpenCode.

## Arquivos importantes
- [../AGENTS.md](../AGENTS.md): instruções principais do repositório.
- [opencode.json](opencode.json): configuração local do OpenCode para o projeto.
- [../docs/prompts-ia.md](../docs/prompts-ia.md): registro obrigatório de prompts de IA.

## Regras
- Sempre seguir o AGENTS.md do projeto.
- Preferir mudanças pequenas e focadas.
- Validar com `dotnet build` após ajustes em C#.
- Dar respostas em português do Brasil.
