## Reporting a Vulnerability

Use this section to tell people how to report a vulnerability.

Tell them where to go, how often they can expect to get an update on a
reported vulnerability, what to expect if the vulnerability is accepted or
declined, etc.
=======
This project does not publish versioned releases. Only the latest commit on
the `main` branch is supported for security updates.

## Reporting a Vulnerability

If this repository is hosted on GitHub and Security Advisories are enabled,
please use that private reporting channel. Otherwise, open an issue with
`[security]` in the title and include:

- affected area (page or component)
- steps to reproduce
- impact
- proof of concept (if safe)
- commit hash or version

Please avoid sharing sensitive data in a public issue. We will try to
acknowledge reports within 7 days.
